Time and Space Complexity

Time Complexity is the amount of time taken by the compiler to run the problem or the algorithm. Time Complexity describes how long an algorithm takes to run as the input size grows (usually denoted by n). The efficient the code the minimum the Time Complexity.

Space Complexity is the total space taken my algorithm or Space complexity measures how much memory an algorithm uses relative to input size. if an array of size n than Space Complexity is O(n)
